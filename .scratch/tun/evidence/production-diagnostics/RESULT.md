# Production Core diagnostic integration

Production service now uses the same bounded capture implementation as both Core experiment callers. Runtime starts require two valid pipe writers; stdin remains closed through `/dev/null`, and process ownership, authentication and network gates are unchanged. Each stream retains at most 64KiB while continuing to drain excess output. Actual held-child waitpid exit/signal evidence is available in production.

After authorization and fixed Core checks, the service creates a protected root-owned `0700` UUID directory beneath `/Library/Application Support/Clash Kuro/TunDiagnostics`. Its five `0600` files contain redacted configuration, launch metadata, stdout, stderr and diagnostic/termination/network-recovery summaries. The actual configuration digest is retained. Only the closed schema's controller secret and proxy username/password are supported; raw and runtime JSON/YAML escaped forms are redacted before persistence. Metadata strings are redacted before JSON serialization, preserving JSON structure. This does not promise detection of arbitrary encodings or derived secrets.

After reap, diagnostic finish is attempted before network recovery. Diagnostic failure does not short-circuit network recovery. Work removal and successful stop acknowledgement require durable diagnostics plus successful recovery through the existing ownership checks. Setup failure without a child also saves a terminal diagnostic. Unexpected stop reasons are recorded before stop, not only after cleanup. Original startup/termination errors are kept separately from logging errors. Diagnostics are deliberately retained by uninstall, whose successful output now states the fixed retained path; they are not process, network or uninstall ownership evidence.

The independent reviewer found and verified fixes for missing late stop reasons and missing no-child setup terminal evidence. The implementation also fixes the observed ARC error-writeback loss in the cancelled-resume case and returns the final success value after `finally`. The exact reviewed five-file patch hash and source hashes are in `native-freeze.json`.
