## 验收标准

- 固定安装目标和 root-owned 目录；拒绝任意 executable/目标路径、目录逃逸、symlink、可写祖先、setuid/setgid 位及未核验产物。摘要须核对固定产物字节，不能用压缩包摘要代替解压后 Core 摘要。
- 管理员确认后在受保护 staging 中重新核验，再提交版本；旧 writer 停止确认前不得并行启新版本。身份/升级记录不允许由普通 RPC 任意修改。
- 取消授权、部分复制、摘要不符、注册失败、升级中断、清理失败及部分卸载均有可观察状态；停止/归属未知时保留恢复所需组件和记录，不宣称卸载完成。
- 只删除清单确认的本产品组件；不改 SIP/Gatekeeper，不设置 Core setuid。隔离测试给出命令与结果，真实权限/安装另记 08。
