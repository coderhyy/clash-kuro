## 负责范围

本功能集成测试、最终 CI/打包结果及 `../acceptance.md`。主会话独占 Git rebase/合并和公共接线。每份真实结果注明源码 commit、App/helper/Core 身份和适用平台，不跨产物直接复用验收结论。

## 验收标准

- 开启/关闭、切换 Profile/Override、普通停止/退出、拒绝授权与启动失败均符合 D3；类型检查及全量受影响自动测试通过。
- 当前操作前先备份/读回系统网络基线，停止或失败后用可观测证据验证路由/DNS、代理和准确进程状态。遇未知则停新写入并按已批准恢复路径处理。
- Windows 取消会话/恢复继承 07 的独立结果；macOS 的对应必要关闭/权限结果按 02/03 选定机制验证。只有实际执行的案例记通过。
- 不泄露 Profile/订阅密钥、私有证据；升级/卸载边界按批准的最小范围验证，签名不足等阻塞如实保留。
- 同机器系统状态操作由主会话串行调度，worktree 只隔离源码；Linux、自动更新和未经选择的可靠性矩阵不进入本票。
