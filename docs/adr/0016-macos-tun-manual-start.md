# macOS TUN 每次启动均由用户手动开启

Status: accepted

2026-11-04 维护者批准：正常退出后重开 App，TUN 仍保持关闭，先检查并恢复本应用残留，完成后由用户手动开启。此决定也适用于登录启动，不持久化或恢复上次 TUN 启用偏好；异常启动继续遵守 ADR-0014 的先恢复、无法确认则提示并阻止新写入。

IPv4-only 未获批准，DNS/路由范围仍待选择，不因本决定关闭用户 IPv6 或宣称全流量接管。实现和验收按现有 04 helper、06 TUN 接入与生命周期、08 集成验收三个交付单元跟踪；不再为内部技术层新增票。本决定仍不是任何真实系统操作的“开始”授权。
